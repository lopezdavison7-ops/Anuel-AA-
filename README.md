# 🎤 ANUEL AA BOT

> **Real Hasta La Muerte 💯**
> Bot de WhatsApp para Managua, Nicaragua 🇳🇮

## 🚀 Instalación

```bash
git clone https://github.com/tu-usuario/AnuelAA.git
cd AnuelAA
npm install
npm start
```

## ⚙️ Configuración

Edita `config.js` y pon tus API keys.

## 📱 Comandos

| Comando | Descripción |
|---------|-------------|
| `.menu` | Menú completo |
| `.ping` | Velocidad del bot |
| `.p` | Ping rápido |
| `.ia` | Inteligencia artificial |
| `.tiktok` | Descargar TikTok |
| `.yta` | Audio YouTube |
| `.daily` | Recompensa diaria |
